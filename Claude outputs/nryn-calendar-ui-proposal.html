Header

Now: brand, date stamp, toggle, Sync, bell and Signals bar all stacked
  • One big serif date, plus a small kicker like "TODAY · 3 LEFT"
  • Sync, bell and menu become 34px round icons on the right
  • Day / Week / Month segmented control
  • Signals bar becomes a single "2 to review" chip that opens the approvals sheet

Week strip (new)

  • Swipe the strip to change week, swipe the timeline to change day
  • Up to 3 coloured dots per day, one per event category
  • Replaces the "Today" jump button: tapping the date title returns to today

Timeline

Now: a ＋ button on every hour, card height capped at 110px
  • Tap or long-press-drag on empty space to create; one floating "+ Add" button
  • Card height matches real duration, so a 90-min block looks 90 min long
  • "1h 20m free" markers in gaps; sleep hours collapsed
  • AI-suggested items appear as dashed ghost cards with ✓ / ✕ inline

Colour & tags

Now: 7 tag styles with different colours and emoji
  • Colour = category (left bar and fill)
  • Source = one small neutral badge (G, ✉, 📝, 🏃)
  • So the colours always mean the same thing

Month view

  • Light green heat fill shows how busy each day is
  • Multi-colour dots instead of a single dot
  • Agenda as a draggable bottom sheet; pulling it up shrinks the month to one week (like Google Calendar)

Add task

Now: free-text HH:mm inputs and colour names (peach/green…)
  • Natural-language input first, parsed into chips
  • Duration chips instead of typing an end time
  • Pick a type (Health/Work/People…) and let it set the colour
  • Google sync as a switch that remembers your last choice
